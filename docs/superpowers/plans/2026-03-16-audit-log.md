# Audit Log System Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an immutable, append-only `audit_logs` table and wire non-blocking audit writes into every mutating Users service method.

**Architecture:** A new `AuditLogRepository` in `features/audit-log/` handles all DB writes. `AuditMeta` type is exported from `lib/services/wrapper.ts`. Each mutating `UserService` method receives `actorId`, fetches a before-snapshot where needed, performs its main operation, then fires a non-blocking `.catch()`-guarded audit write.

**Tech Stack:** Next.js 15, Drizzle ORM, PostgreSQL 16, TypeScript (strict), `npx tsc --noEmit` for type-checking, `drizzle-kit generate` + `drizzle-kit migrate` for schema migrations.

### Task 3: Create `AuditLogRepository`

**Files:**
- Create: `features/audit-log/repositories/audit-log.repository.ts`

- [ ] **Step 1: Create the directory and file**

```bash
mkdir -p features/audit-log/repositories
```

Create `features/audit-log/repositories/audit-log.repository.ts`:

```ts
import { db } from '@/db/drizzle'
import { auditLogsTable } from '@/db/schema'
import { executeQuery } from '@/lib/queries/wrapper'
import type { AuditLogInsert } from '@/db/schema'

export class AuditLogRepository {
  private static readonly context = 'AuditLogRepository'

  static async create(data: AuditLogInsert): Promise<void> {
    return executeQuery(
      { context: this.context, method: 'create' },
      async () => {
        await db.insert(auditLogsTable).values(data)
      }
    )
  }
}
```

**Notes on this implementation:**
- `executeQuery` takes two arguments: `(config: QueryConfig, handler: () => Promise<T>)`. This matches the pattern used throughout the codebase (e.g. `UserRepository`).
- No optional `tx: DbTransaction` parameter is included. Audit log writes are intentionally independent — they must not participate in the calling service's transaction, because we want the audit entry to persist even if a hypothetical caller later rolls back. Keeping it outside any transaction is the correct pattern for a non-blocking fire-and-forget write.
- Import `AuditLogInsert` as a type import (`import type`) to keep the bundle clean.

## Chunk 2: Service Layer Wiring

### Task 4: Update `UserService` — add `actorId` + audit calls

**Files:**
- Modify: `features/users/services/users.service.ts`

The current `UserService` has 5 mutating methods: `create`, `update`, `changePassword`, `toggleStatus`, `delete`. Each needs:
1. `actorId: number` as second parameter (after `companyId`)
2. A before-snapshot fetch where required (see table below)
3. A non-blocking audit write after the main operation succeeds

| Method | Before snapshot needed? | `changes` shape |
|---|---|---|
| `create` | No | `{ after: newUser }` |
| `update` | Yes — `findById` before update | `{ before: oldUser, after: updatedUser }` |
| `changePassword` | No | `{ before: { id }, after: { id } }` |
| `toggleStatus` | Yes — `findById` before update | `{ before: { isActive }, after: { isActive } }` |
| `delete` | Yes — `findById` before softDelete | `{ before: oldUser }` |

- [ ] **Step 1: Update `create`**

Replace the existing `create` method with:

```ts
static async create(
  companyId: number,
  actorId: number,
  data: CreateUserDto
): Promise<UserSafe> {
  return executeService(
    { context: this.context, method: 'create', logParams: { companyId } },
    async () => {
      const existing = await UserRepository.findByEmail(companyId, data.email)
      if (existing) throw new ConflictError('A user with this email already exists')

      const passwordHash = await hash(data.password, 10)

      const newUser = await UserRepository.create(companyId, {
        email:       data.email,
        passwordHash,
        role:        data.role,
        employeeId:  data.employeeId ?? null,
        isActive:    true,
        lastLoginAt: null,
      })

      AuditLogRepository.create({
        companyId,
        actorId,
        entity:   'users',
        entityId: newUser.id,
        action:   'create',
        changes:  { after: newUser },
      }).catch((err) => logger.error({ err }, 'Audit log write failed'))

      return newUser
    }
  )
}
```
